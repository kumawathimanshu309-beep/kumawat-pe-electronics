🔌 Connect a Real Backend

Right now this portal saves data in your browser (localStorage). To make bookings and users persist across devices and sessions, connect a real database. Both options below are free to start.

Firebase Google

Easy auth, real-time Firestore database, free tier generous. Best for quick setup.
firebase.google.com →

Supabase Open Source

Postgres database + Auth + APIs. More control, excellent free tier. Ideal if you want SQL.
supabase.com →

1

Create a free project

Sign up at firebase.google.com or supabase.com. Create a new project named "sharma-pe". Both have generous free tiers — no credit card needed to start.

2

Enable Email/Password Auth

Firebase: Console → Authentication → Sign-in method → Email/Password → Enable.
Supabase: Dashboard → Authentication → Providers → Email → Enable.

3

Create the bookings table (Supabase) or collection (Firebase)

-- Supabase SQL Editor: CREATE TABLE bookings ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, name text NOT NULL, phone text NOT NULL, email text, service text NOT NULL, address text, date date, time_slot text, notes text, status text DEFAULT 'pending', created_at timestamptz DEFAULT now() );
4

Get your API keys

Firebase: Project Settings → Your apps → Add web app → copy config object.
Supabase: Project Settings → API → copy URL and anon key.

// Firebase config looks like: const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "sharma-pe.firebaseapp.com", projectId: "sharma-pe", ... }; // Supabase config looks like: const supabase = createClient( 'https://xyzcompany.supabase.co', 'your-anon-key' );
5

Replace localStorage calls in this file

Search for getUsers() and getBookings() in this HTML file and replace with Firebase/Supabase SDK calls. The data structures are identical — it's just swapping the storage layer.

6

Set admin role via custom claims

After connecting, set your admin email's custom claim using Firebase Admin SDK or Supabase RLS policies so only admins can see the Users tab and manage other users.

// Firebase Cloud Function to set admin claim: exports.setAdmin = functions.https.onCall(async (data, context) => { await admin.auth().setCustomUserClaims(data.uid, { admin: true }); return { success: true }; });

Need help? Share this file with a developer and point them to this page. The data structures, UI, and logic are all ready — they just need to wire in the SDK. Estimated time: 2–4 hours for a developer familiar with Firebase or Supabase.
