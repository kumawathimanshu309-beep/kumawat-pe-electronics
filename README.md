# Kumawat P&E Electronics Store

A premium, production-ready full-stack eCommerce application for Electronics and Electricals. Built with Express.js, EJS, and MongoDB.

## Features
- **Premium UI/UX:** Responsive, modern design with hover interactions, skeleton loaders, and dynamic shopping carts.
- **Complete Checkout Flow:** Secure cart management with Coupon integration, Taxes, Delivery, and Razorpay.
- **Admin Dashboard:** Comprehensive admin suite to manage orders, coupons, products, and users.
- **Security & Performance:** Hardened with Helmet, Express Rate Limiting, Winston Logging, Morgan, and Compression.
- **SEO Optimized:** Dynamic JSON-LD structured data, XML Sitemap, and semantic meta tags.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Templating:** EJS
- **Frontend:** Bootstrap 5, Custom CSS Variables
- **Payments:** Razorpay
- **File Uploads:** Multer, Cloudinary

## Quick Start
1. Clone the repository
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in your keys
4. Run `npm run start`

## Deployment
This project is natively configured for deployment on Vercel. Simply connect your GitHub repository to Vercel and it will automatically deploy using `vercel.json`.
